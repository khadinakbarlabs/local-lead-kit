# Looksy Agent

The public Research Guide and private Local Leads share a paper surface, ink typography and evergreen controls. The two eyes in the [mark](mark.svg) echo the double “o” in Looksy. The [README preview](guide-preview.png) shows the actual released guide with illustrative data.

| Color | Role | Hex |
|---|---|---|
| Paper | Workspace background | `#F5F5EF` |
| Ink | Text | `#192B23` |
| Evergreen | Primary action and active step | `#216246` |
| Rule | Field and section dividers | `#C7CFC4` |

Keep `looksy` in installation commands and links.
