# Validation evidence

Checked 3 November 2026. This is an initial open-source resource, not a plugin-directory approval.

- 25 offline behavioral tests passed on Python 3.11 and 3.13. They cover input bounds, approved reservations, uncertain starts, known-run readback, partial/error states, stable joins, basic-check limits, CSV safety, attribution, API paging and local HTTP authorization.
- Real read-only API calls verified the current public Actor identities, builds, schemas and prices. The Maps schema currently permits maxResults up to 5,000.
- A real 1,000-target/three-territory plan was prepared in the app. It was not approved or started.
- Three existing tutorial runs were imported read-only: 18 businesses, 15 unique addresses, partial coverage and zero confirmed mailboxes. No new paid Actor runs were started for this resource validation.
- The active assistant added 18 source-cited review notes. Three official websites were inspected; other notes explicitly identify saved-data limitations.
- Claude's native plugin and marketplace validators passed. Codex marketplace registration and plugin installation succeeded. Both isolated native archives passed resource-closure and helper-execution checks. The public repository CI passed its test and package checks.

A requested target is not a verified live campaign result. An offline worker test is not a live paid-start test. Native installation, automatic host skill selection and marketplace approval remain separate claims.

Version 0.2: verified 659 unique public Store entries and read live default build, input schema and event pricing for complete-seo-audit, dataforseo-keyword-research, keyword-rank-tracker, ai-search-visibility-tracker, ai-citations-tracker, ai-text-humanizer and google-maps-leads-scraper on 2026-11-04. No paid run was used for these checks. All four archives are extracted and their discovery commands exercised by package validation. This is not evidence of an interactive launch in every host or a live execution of every listing.

Seven example input sets also produced read-only, build-pinned plans without starting collection. A clean local Codex marketplace install reported 0.2.0 enabled, Claude validated both manifests, and headless Chrome rendered 659 matches in the visual catalog. Cursor and portable packages were verified after extraction, not through interactive installation.

## Looksy Agent 0.7.0

Checked 7 November 2026. This release aligns the connector guidance and local runtime with the documented Apify connection, permission and pricing contracts. The local MCP now previews paid actions, binds approval to the account and exact plan, preserves known runs after read failures, and supports separately approved repeat research. The shared client verifies Actor and build permissions and forces limited permissions on starts. All local paid paths supply the reviewed metadata hash to the final pre-start check. CLI plans also bind the verified account.

The local suite ran 124 tests successfully, with two Windows-only tests skipped on macOS and assigned to Windows CI. Offline regression tests cover full/unknown permissions, public metadata without ambient credentials, current price records and tiers, minimum caps, account changes, metadata drift, approval replay, unknown starts, older confirmed-run replay, terminal partial evidence, malformed reads and safe errors. Cost checks use Apify's eventUsage, usageUsd and usageTotalUsd fields to avoid double counting. No paid execution was used for this release.

Read-only public API inspection verified the Maps Actor's exact build 1.8.8, limited permissions and three current events. Browser checks cover required local setup, optional-provider skip/settings, history, guide routing and campaign drafts. Native archives are extracted into temporary directories and their declared entrypoints are exercised with each documented install-root variable expanded. This establishes packaged entrypoint closure, while actual interactive host loading and OAuth completion require separate observation.

The repository's unit suite, archive validator and Claude manifest validator are the release checks. The generic Plugin Builder release checker assumes that builder's own npm package identity and does not apply to this Python repository. Hosted interactive OAuth, live paid/non-owner execution, settled invoices, all catalog Actors and platform directory approval were not validated for this release. Source-rights review remains specific to each workflow.
