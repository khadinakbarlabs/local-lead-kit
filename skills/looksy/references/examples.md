# Example deliverables

These examples illustrate structure. Replace them with observed source data after research.

| Outcome | Artifact columns |
|---|---|
| Prospect research | Business, location, website, public contact, source URL, observed checks, missing fields |
| SEO audit | Affected URL, observed issue, supporting evidence, priority rationale, suggested action |
| AI visibility | Prompt, provider, live/simulated status, observed mention, cited source, date |
| Product comparison | Product and variant, seller, price, currency, availability, observation date, source |
| Conversation analysis | Topic, dated source message/thread, supported theme, question or objection, sample coverage |
| Job shortlist | Role, employer, location eligibility, posted pay when available, date, apply URL |

Show the requested artifact shape before connection. Keep missing values visible. For a research plan spanning sources, use the workflow reference and inspect actual intermediate results before selecting downstream inputs.
