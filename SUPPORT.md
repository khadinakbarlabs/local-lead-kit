# Support

Use [GitHub Issues](https://github.com/khadinakbarlabs/local-lead-kit/issues) for bugs and feature requests. Include the version, host (Codex, Claude Code or standalone), expected behavior and a small synthetic example.

Do not include credentials, private launch links, server-access files, live run IDs or contact datasets. For an uncertain paid start, inspect the saved campaign with your assistant before trying again. GitHub availability is separate from plugin-directory approval.
